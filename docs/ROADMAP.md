# Implementation roadmap

1. Foundation: Django project, PostgreSQL settings, custom user, initial academic entities, API health, desktop shell.
2. Authentication and dashboards: role-aware web and desktop sign-in, permissions, dashboards.
3. Student/faculty management: CRUD, search, import/export.
4. Attendance: class/subject attendance, calculations, shortage reporting.
5. Examinations: schedules, marks, configurable grading and results.
6. Timetable and communication: allocations, announcements, leave requests.
7. Reporting: PDF/Excel and academic analytics.
8. QA and deployment: automated tests, security hardening, backups, web hosting and desktop packaging.

The official department list, programs, semester rules, attendance rules and grading scheme must be confirmed with the college before production configuration.
